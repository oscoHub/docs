Each platform decides what it shares, so the columns you see depend on the channel.

| Platform | Views | Reach | Reactions | Comments | Shares | Reposts | Quotes | Saves |
|---|---|---|---|---|---|---|---|---|
| **Facebook** | ✓ | ✓ | ✓ | ✓ | ✓ | | | |
| **Instagram** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | | ✓ |
| **LinkedIn** | ✓ | ✓ | ✓ | ✓ | | ✓ | | |
| **Threads** | ✓ | | ✓ | ✓ | ✓ | ✓ | ✓ | |
| **YouTube** | ✓ | | ✓ | ✓ | | | | |
| **Bluesky** | | | ✓ | ✓ | | ✓ | ✓ | |
| **Telegram** | | | | | | | | |

## Exceptions

- **Facebook stories** have no statistics.
- **Instagram stories** share views, reach, comments, shares and reposts.
- **Telegram** doesn't share how individual posts performed.

## What the numbers mean

| Number | Meaning |
|---|---|
| **Views** | How many times the post was seen, as the platform counts it. |
| **Reach** | How many people saw it, as the platform counts them. |
| **Reactions** | Likes and other reactions. |
| **Comments** | Comments or replies. |
| **Shares** | Times it was shared. |
| **Reposts** | Times it was reposted. |
| **Quotes** | Times it was quoted. |
| **Saves** | Times it was saved. |

Numbers in OSCOHub come from the platform, and platforms update them at different speeds. They can differ for a while from what you see on the platform itself. See [when numbers update](/insights/overview#when-numbers-update).
